# 2026-10-03 入力エラーと表示の改善

開局・締め画面の現金入金は、開局未選択・理由未入力でも送信でき、Zodの内部JSONがそのまま表示されていた。開局記録・理由・整数円の入力が揃うまで入出金を止め、必要な入力を各項目のそばで案内するよう変更した。未選択の端末暫定締めと不正金額の開局も送信を止める。

APIの入力検証は400・`INVALID_INPUT`・`retryable:false`を維持し、項目別の日本語`fieldErrors`と入力修正の案内を返す。共有の厳密なエラーDTOにもoptionalの`fieldErrors`を追加した。同期の入力不備は引き続きBusinessErrorとして要確認記録へ永続化する。旧APIが内部JSONを返す場合もWebで利用者向け文言へ変換する。

初回の確定400は入力修正できる。先に通信断などで保存結果が未確認になっていた操作が後に400となった場合は、入力を変えず保存結果を照会するよう案内する。元の操作ID・送信内容・未確認状態を保持する既存の仕組みは維持した。

AIの集計選択肢は「売上・支払方法別売上・概算粗利・在庫・発注」と表示し、APIの集計キーは変更しない。開局一覧も端末UUID・英語状態から端末名・「開局中／暫定締め済み」へ変更した。

新規9試験をRed→Greenで追加した。元の試験名・期待値は保持する。独立した画面レビューでは390px・1280pxで横はみ出しと未処理例外がないことを確認した。AWS配備、正式提出資料、Roomスキーマの変更は行わない。
